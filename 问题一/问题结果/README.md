# 第一问结果

- `数据表格/`：连续预测指标、外层预测和七点评分表。
- `数据表格/数据清洗/`：清洗后的特征、标签及缺失、重复、异常、参考冲突等核验表。
- `绘图/`：总览图及逐属性 R² 图。
- `模型/`：可直接用于新样本预测的统一模型。
- `元数据/`：数据审计、验证协议、汇总指标与验证范围。
- `历史完整实验/`：完整五折实验原始产物；`历史实验/`：早期基线对照。

当前七点评分属于基于经验锚点的模型估计；绝对强度锚点尚未人工校准。

数据清洗结论见[数据清洗报告](数据清洗报告.md)。`元数据/cleaning_summary.json`记录核验结果和保留策略。清洗表中的NA由模型在训练折内填补，不能先用全体样本填好再评价泛化。
