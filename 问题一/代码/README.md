# 第一问代码

主程序只有一个文件：[question1.py](question1.py)。它独立完成数据审计、建模验证、七点评分、图表和模型导出；依赖版本列在同目录的 `requirements.txt`。

使用 `--clean-only` 可单独重跑完整清洗核验，导出清洗特征/标签、缺失分布、重复检查、尺度字典、异常标记和来源逐值比对。完整训练入口会先执行同一清洗流程。无需联网；若本地已有作者公开补充工作簿，还会核对作者S1/S4与附件是否一致。

旧版拆分模块保存在 `历史模块/`，供追溯；首轮实验代码及产物归档在[问题结果/历史实验](../问题结果/历史实验/初次未约束线性模型/)。
