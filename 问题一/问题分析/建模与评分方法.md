# 建模假设、评分公式与可靠性边界

本文给出第一问"可复算"的部分：变量、公式、假设、等级语义，以及哪些结论有证据、哪些只能写成限制。数据核验见[评分卡到输出对应关系](题意与数据核验.md)与[特征尺度解释](题意与数据核验.md)，结果数字见[第一问结果分析](第一问结果分析.md)。

## 1. 变量与记号

| 记号 | 含义 | 来源 |
|---|---|---|
| `X ∈ R^{250×231}` | 化学/理化特征矩阵 | `1.csv` 第 4 列起 |
| `Y ∈ R^{250×50}` | 标准化感官目标 | `4.csv` 第 4 列起 |
| `M ∈ {0,1}^{250×231}` | 缺失掩码，`M=1` 表示缺失（73 处） | `1.csv` 的 NA |
| `j = 1…50` | 目标索引；`j ∈ core` 为 Aroma/Flavour 30 项 | 见字段字典 |
| `I, C, S` | 中位数填补、1%—99% 分位裁剪（仅线性/PLS 分支）、特征标准化 | 均在训练折内拟合 |
| `f_j` | 第 j 个属性的回归器（由内层验证从候选家族中选出） | 见第 2 节 |
| `G_j` | 连续预测到 0—6 的分级函数 | 见第 3 节 |

## 2. 预测公式与训练流程

对任意输入 `x`（允许含缺失）：

```text
z = S(C(I(x)))            # 线性 / PLS 分支
z = S(I(x))               # 树模型分支
ŷ_j = f_j(z)              # 连续预测，已反标准化为附件标签尺度
```

- 候选家族：岭回归（α=10/100/1000）、PLS（5/12 个成分）、ExtraTrees（叶节点 2/6）、逐属性 ExtraTrees、逐属性直方图梯度提升、两种固定等权融合、训练折均值基线。目标值在 `TransformedTargetRegressor` 内标准化，预测时反变换，因此 `ŷ` 与 `4.csv` 同尺度。
- 外层 5 折、内层 3 折；每个属性只按内层 OOF MSE 选一个候选。外层测试样本的标签不参与插补、裁剪、标准化、选模或分级锚点。
- 缺失值不做全局填补：73 处缺失保留为 NA，填补器在每个训练折内用训练样本中位数拟合。这一点直接关系到第四节的缺失实验是否可信。

## 3. 七点分级公式

对每个属性 j，只用该外层折的训练标签确定三个参照位置：

```text
L_j = min(训练标签)                                  → 假定 0 分
M_j = 高于 L_j 的观测中最接近其中位数的实际观测      → 假定 3 分
H_j = 高于 L_j 的观测中最接近其 95% 分位数的实际观测 → 假定 6 分
```

连续估计与整数等级：

```text
        ⎧ 0                                y ≤ L
        ⎪ 3·(y−L)/(M−L)                 L < y ≤ M
s_j(y) = ⎨
        ⎪ 3 + 3·(y−M)/(H−M)             M < y < H
        ⎩ 6                                y ≥ H

g_j = floor(s_j + 0.5)
```

- 分段线性保证单调：`y` 增大时 `g` 不减，端点严格取 0 与 6。
- 只取实际观测值作为锚点，不取插值分位点，便于复核"哪个啤酒是参照"。
- 若某属性在训练折内可区分的观测不足（`two_anchor_fallback`），中锚取 `(L+H)/2`；若连强度范围都识别不出（`no_identifiable_intensity_range`），该属性记为无法分级，不返回静默的 0。当前 49 项均为 `three_reference_candidates`。
- 有标签的样本其 OOF 等级只用该样本所在外层折的训练锚点；给新样本用的全样本锚点另存于`七点评分/reference_candidates_and_assumptions.csv`（`fit_scope=all_250_for_future_predictions`）。

**算例**（用全样本锚点，即新样本路径）。以 `alcohol` 为例，`L=-2.150729`、`M=-0.015684`、`H=1.267059`；取一个预测值 `y=0.645`：

```text
y > M  → s = 3 + 3·(0.645+0.0156841)/(1.2670587+0.0156841) = 3 + 3·0.51506 = 4.545
g = floor(4.545+0.5) = 5
```

同一分数在不同属性上不可互换：`s=5` 在 `alcohol` 上表示"接近该属性参考高端"，在 `barnyard` 上则是另一个感官量，二者没有共同的物理强度单位。

## 4. 假设清单与验证状态

| 编号 | 假设 | 状态 | 依据 / 影响 |
|---|---|---|---|
| A1 | `4.csv` 的列与卡片项目同义 | 已逐项核对 | 50 列 = 49 个强度项目 + `overall`；名称、父组、单元格逐项对上。语义相同取自同一评分卡模板，非独立复测 |
| A2 | 标准化标签不能唯一反推原始 0—6 | 已论证 | 逐品评员中心化/标准化后，任意平移可得到同一标准化值；作者未公开原始逐人分数 |
| A3 | 等级随预测强度单调 | 由公式保证 | 分段线性 + 取整；已逐属性验证端点与单调性 |
| A4 | 训练最小值≈0 分、上四分位附近≈6 分 | **经验假设，未校准** | 最低观测可能仍属"微弱可感知"；高端候选未必是"极强"。`ISO 13299` 与 `GB/T 29604` 只提供建立参照样的程序，不给出本题各属性的数值 |
| A5 | 样本可交换 | 部分满足 | `KFold` 随机划分，评估的是同一总体的新样本；未验证新地区、新工艺、未见风格 |
| A6 | 缺失可填补、且缺失机制不改变结论 | 有限证据 | 73 处缺失中 `aroma_hops_sum` 与 Hoppy 风格有关联（BH 校正 p≈0.0100），因此不能假定完全随机。缺失下的表现另行量化（第 6 节） |
| A7 | 属性间独立建模足够 | 已知近似 | 卡片层级（子项继承组分强度）使标签天然相关；逐属性回归未利用该结构，代价是效率而非正确性 |

## 5. 等级语义

| 等级 | 本项目用语 | 依据与边界 |
|---:|---|---|
| 0 | 未感知 | 卡片端点（`C=0`）＋"训练最低观测"锚点；模型估计为 0 **不等于**实验确认不存在 |
| 1 | 极弱 | 项目用语，非标准逐级定义 |
| 2 | 弱 | 同上 |
| 3 | 中等 | 项目用语；同时是"高于最低值部分的中位数附近观测"这一经验锚点 |
| 4 | 较强 | 项目用语 |
| 5 | 强 | 项目用语 |
| 6 | 极强／占主导 | 卡片端点（`O=6`）＋"高于最低值部分 95% 分位附近观测"锚点；未经人工强度校准 |

七级是**有序等级**，不是等距量表：4 分不表示 2 分的两倍，不同属性的同一分值不表示等强度。这一点与 `GB/T 39501—2020` 6.4 的提醒一致（数字刻度不自动保证感知强度等距）。

## 6. 模型选择与可靠性的表述口径

- 主评价对象分两套报告：核心 30 项（Aroma/Flavour）与全体 50 项。两者不可相互替代。
- 逐属性选择模型（`nested_selected`）在全体 50 项上宏平均 R² 0.2448、核心 30 项 0.2010；固定树融合 `blend_tree_only` 是 0.2508 / 0.1982。因此"逐属性选择"在总体上**不是最优**，其价值在于让弱目标回退到均值基线、避免单一模型在弱目标上更差。文中不称其全面最优。
- 逐属性可靠性按外层 OOF R² 分档（阈值是项目自定，仅用于阅读）：

| 档 | 判据 | 表述 |
|---|---|---|
| 可用 | R² ≥ 0.4 | 可作为该属性的估计，仍非原始 0—6 分 |
| 中等 | 0.2 ≤ R² < 0.4 | 方向可用，等级细节不可靠 |
| 弱 | R² < 0.2 且不低于该属性的训练均值基线 | 接近均值预测，等级只能作参考 |
| 低于基线 | R² < 该属性的 `baseline_r2` | 不应作为该属性的评分 |

"低于基线"按**逐属性与自身的训练折均值基线比较**判定，而不是简单用 `R² < 0`：R² 的零点等于"按该属性总体均值预测"，而训练折均值基线的 R² 略小于 0（本项目 −0.0004 至 −0.0267），两者并不等价。改用严格比较后，被判为低于基线的仍是 `A_esters_flower`（−0.0311 vs −0.0067）与 `F_esters_flower`（−0.0725 vs −0.0084）两项；其余负值项目不存在，结论不变。

具体哪些属性落在哪一档见`数据表格/per_target_metrics.csv`的 `reliability` 列与结果分析中的弱属性表。R² 为负或接近 0 的项目一律不宣称"能准确评分"。

- 敏感性不等于准确率：高端锚点换成 90%/99% 分位时等级改变比例约 20.56%/18.22%，这是"锚点选择的影响"，不是误差或准确率。锚点自助抽样给出的经验等级范围同样只反映锚点不确定性，不含重训变异。
- 缺失压力实验回答"测量缺失时还能不能评分、误差增加多少"，与预测误差、锚点敏感性、区间覆盖率各自回答不同问题，不能相互替代。两种遮蔽方案的横轴都是"在各自选定列内"的追加遮蔽比例：随机方案作用于 231 列，定向方案只作用于 9 列，30% 时仅相当于全部 250×231 个单元格的 1.17%，因此两条曲线不能当作同等缺失总量下的比较。
- 关于选择偏差的披露：候选模型集合在首轮诊断（未约束线性模型严重外推）之后做过修订，因此本次外层结果属于本数据上的开发验证，不是预先注册的完全独立验证；若再依据外层结果调参，就必须换一套新验证，本文未这样做。

## 7. 等级分布的一个必须说明的现象

250×49 个评分单元中，等级 3 占约 54.7%（6699/12250），等级 4 占 26.7%。原因是连续预测向均值收缩后，多数啤酒落在中锚附近；这是"回归到均值 + 分段锚点"的直接结果，**不代表所有啤酒的感官强度都中等**。解释单个啤酒时应同时给出该属性的可靠性档与连续预测值，而不是只看整数等级。

## 8. 不能声称的结论

1. 不能声称恢复了原始人工 0—6 分，或给出"原始等级准确率"；没有原始标签，任何用自映射伪标签算出的准确率都是循环论证。
2. 不能把附件尺度的 MAE/RMSE 写成"0—6 分误差"。
3. 不能把 0 解释为"该风味不存在"，也不能把 6 解释为"达到行业标准的最强"。
4. 不能把 `7.csv` 的文本权重当作乙醛或任何属性的面板标签。
5. 不能把缺失压力实验外推到检测限以下、整类化合物缺失等未模拟的机制。
6. 不能把区间覆盖率理解为"50 项同时覆盖"的保证。


## 9. 量表来源与等级用语

### 采用的既有方法

- 来源研究采用七点强度量表，并用参考啤酒做品评校准：[Schreurs 等，2024](https://www.nature.com/articles/s41467-024-46346-0)。
- QDP 的标度选择与参照原则见 ISO 13299:2016 的 6.2.5 与附录 F；参比样的建立参考 GB/T 29604—2013。条款与页码见[感官评分标准检索](参考资料/感官评分标准检索.md)与[全文核对结论](参考资料/全文核对结论.md)。
- GB/T 39501—2020 的 6.4 提醒数字刻度不自动保证感知强度等距；本项目因此把等级当作有序量，不把不同属性的同一分值解释为等强度，也不把 6 分解释成 3 分的两倍。
- Spectrum 的 0—15 尺度不用于本版：现有数据不含其实际参照强度，再换算一次不会增加校准信息。

### 七点定义

| 等级 | 本项目采用的描述 | 依据 |
|---:|---|---|
| 0 | 未感知 | 卡片端点；模型估计依赖锚点假设 |
| 1 | 极弱 | 项目采用的中间等级用语 |
| 2 | 弱 | 同上 |
| 3 | 中等 | 同上；同时是"高于最低值部分中位数附近观测"这一经验锚点 |
| 4 | 较强 | 项目采用的中间等级用语 |
| 5 | 强 | 同上 |
| 6 | 极强／占主导 | 卡片端点；高端锚点尚未经人工校准 |

1—5 级用语不是对标准逐级定义的引用。模型估计为 0 也不等于已经实验确认该风味不存在。
