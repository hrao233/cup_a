# 第一问：采用QDP与七点强度尺度的评分方案

本版沿用来源研究的七点强度量表，借鉴定量描述剖面（QDP）及参比样方法，使用现有连续预测产生模型估计分级。没有重新训练化学—感官预测模型。

**已有方法提供尺度和参照原则；本数据中的具体锚点仍是经验候选，未经过真实品评校准。下文不会将经验锚点称为国标已规定的分界。**

## 1. 采用的既有方法

- 来源研究采用七点强度量表，并使用参考啤酒进行品评校准。[Schreurs等，2024](https://www.nature.com/articles/s41467-024-46346-0)
- QDP的强度标度选择和参照原则见ISO 13299:2016的6.2.5、附录F；参比样建立参考GB/T 29604—2013。具体条款和页码见项目的[全文核对结论](../../references/全文核对结论.md)。
- 本项目采用有序等级，不把不同感官属性的同一分数解释成已经证明的等强度，也不把6分解释成3分的两倍。

Spectrum的0—15尺度不用于本版。已有数据不含其实际参照强度，额外转换到该尺度不会增加校准信息。

## 2. 七点定义

| 等级 | 本项目采用的描述 | 依据 |
|---|---|---|
| 0 | 未感知 | 题目评分卡端点；模型输出须依赖锚点假设 |
| 1 | 极弱 | 项目采用的中间等级用语 |
| 2 | 弱 | 项目采用的中间等级用语 |
| 3 | 中等 | 项目采用的中间等级用语 |
| 4 | 较强 | 项目采用的中间等级用语 |
| 5 | 强 | 项目采用的中间等级用语 |
| 6 | 极强／占主导 | 题目评分卡端点；高端锚点尚未经过人工校准 |

1—5级用语不是对国标逐级定义的引用。模型估计为0，也不等于已经实验确认该风味不存在。

## 3. 具体锚点：本题的工作假设

对每个感官属性，先仅使用训练折的感官标签选择三个候选参照位置：

| 候选位置 | 选取规则 | 暂定分值 |
|---|---|---:|
| L：低端 | 训练样本中该属性的最低已观测值 | 0 |
| M：中间 | 高于最低值的观测中，最接近中位数的实际啤酒 | 3 |
| H：高端 | 同一观测集合中，最接近95%分位数的实际啤酒 | 6 |

上述位置是现有数据上的参照候选，不是实验证明的“无、中、极强”。最低值可能仍对应微弱感知；高端候选也未必达到压倒性强烈。因此这一选择属于可审计的估计假设。

候选啤酒的编号、附件尺度值、最低值出现次数和所属训练折都保存在`reference_candidates_and_assumptions.csv`。未来取得真实参照样品的标定结果后，可以替换这三个位置。

## 4. 从连续预测到分级

对第一问已有模型给出的连续预测值y，采用单调分段线性映射：

```text
y ≤ L       → s = 0
L < y ≤ M   → s = 3 × (y − L) / (M − L)
M < y < H   → s = 3 + 3 × (y − M) / (H − M)
y ≥ H       → s = 6

整数等级 g = floor(s + 0.5)
```

s是0—6连续估计值，g是最终整数等级。插值及取整属于本项目的计算规则；它们没有证明真实感知是等距的。该方法不要求七个等级人数相等，也不直接把标准化负值当作0分。

## 5. 输出范围

- 核心结果：Aroma和Flavour各15项，共30项，输出250款啤酒的估计等级。
- 扩展结果：加入19项口感或缺陷强度，共49项。
- `overall`是总体喜好度，保留在原连续预测表中，不混入本强度评分体系。
- 评分卡中的独立Acetaldehyde香气/风味项目缺少相应直接训练标签，本版没有伪造这两个感官分数。
- 按Beer# 1—12另提供评分卡样本的等级表。

## 6. 验证与敏感性

评分使用已有外层5折预测；每折的L、M、H只从该折训练样本选取。测试样本自身的感官标签不参与其评分映射。另用全部250个样本拟合供新样本调用的映射，两者用途分开记录。

连续感官预测的全50维宏平均R²仍为0.2448；新增映射没有提高或重新评价这个预测模型。

将高端参照位置由95%改为90%时，20.56%的估计等级变化；改为99%时，18.22%变化。这衡量对锚点选择的敏感性，不能称为预测准确率。

每个训练折还重采样150次评估锚点变化。54.20%的评分单元具有非零的经验等级范围，平均范围宽度为0.551级。这里只反映固定预测值下的锚点不确定性，没有包含重新训练模型的全部变化，也不是严格覆盖保证。

已检查：训练/测试锚点隔离、参照编号来源、单调性、0—6边界、序列化一致性，以及错误顺序锚点的拒绝。记录见`verification.json`。
