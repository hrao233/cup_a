# 第一问分析

第一问把啤酒化学/理化特征映射到感官属性：化学特征来自 `1.csv`，50个感官目标来自 `4.csv`；其中30个 Aroma/Flavour 属性作为核心评价对象。`3.xlsx` 用于核对评分项目，`8.xlsx` 用于核验属性名称及部分特征量纲。

验证采用外层5折、内层3折。各属性在训练折内独立选择模型，缺失值填补、特征裁剪和标准化不使用测试折信息。当前结果与数据限制详见[结果分析报告](第一问结果分析.md)。

七点评分借鉴QDP及来源研究的七点强度形式；绝对锚点是未经人工感官校准的经验假设，不能视为从标准化标签恢复的原始人工评分。方法细节见[七点评分方案](七点评分方案与结果.md)，标准核对记录在[参考资料](参考资料/感官评分标准检索.md)与[全文核对结论](参考资料/全文核对结论.md)。
