# 第一问数据清洗来源核对

核对日期：2026-10-26。复现入口为`问题一/代码/question1.py --clean-only`，结果见[清洗报告](../../问题结果/数据清洗报告.md)。

## 使用的原始依据

1. 比赛`1.csv`、`4.csv`、`8.xlsx`和数据说明。1.csv为化学预测输入，4.csv为标准化感官目标；8.xlsx的`Sensory thresholds`含231个特征的名称、校准标记与部分单位，`Calibrated chemical dataset`提供70列校准参考。
2. [Schreurs等的论文方法部分](https://pmc.ncbi.nlm.nih.gov/articles/PMC10966102/)：化学测量报告生物重复均值；HS-SPME-GC-MS峰面积经内标归一化；感官评分按品评员中心化及标准化；部分化学特征经过对数变换。
3. [作者公开资料的固定版本10653704](https://zenodo.org/records/10653704)：读取`Supplemental Files and Figure source files.xlsx`的S1、S4及校准工作表，与比赛附件按beer逐值、逐缺失位置核对。
4. 同版本`Main Figure Generator.Rmd`的“calibrated_data / peak_areas”绘图片段：作者对没有绝对校准的峰面积字段使用A.U.。`Machine learning models transcript.py`及`init_modeling.py`说明模型直接使用S1并执行填补、标准化，没有给出全部未校准字段的变换前数据。它们未提供足以逆转161列的逐列原始信号与完整处理链。
5. 补充表S1列出检测方法，S5为化合物/供应商信息，S7为酶法试剂信息；这些不是逐化合物LOD/LOQ表。`Sensory thresholds`描述感官感知阈值，不能代替仪器检出限或化学浓度上界。

## 本次核对得到的处置依据

- 37列在校准正值区间支持log10表示；零及负参考值的低端替代与半个最小正值规则一致。这个数值规则可核对，但不能据此称其为仪器检出限。
- 33列以校准原值表示为主，逐单元格核对发现其中存在差异。仅比较中位数误差会漏检，现已导出全部冲突。
- 其余157列为未校准相对信号、4列为合计信号；保留附件处理后的表示，不推定mg/L，也不再次统一取对数。
- 比赛主表与作者S1/S4一致，校准参考也与作者原表一致。因此跨工作表的不一致已存在于上游；清洗采用比赛主表，不用辅助校准表盲目覆盖。
- 作者公开处理表一致不代表测量准确。极端峰面积或浓度的测量真伪仍需原始色谱、批次与重复测量才能判定；本轮标记后保留，逐项给出来源状态。
- 原作者脚本的填补位置不直接照搬。本项目继续在每个训练折内拟合中位数填补器和尺度变换，避免使用验证样本统计量。
